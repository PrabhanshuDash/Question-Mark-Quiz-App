# Question Mark - Quiz App

Question Mark is a Flutter-based Quiz Application developed for children aged 6–12 years. The application provides interactive educational quizzes across multiple categories including Science, Mathematics, General Knowledge, English, and Sports.

## Features
- Interactive quiz system
- User authentication
- Firebase integration
- Score tracking
- Responsive UI
- Multiple quiz categories

## Technologies Used
- Flutter
- Dart
- Firebase
- FlutterFlow

## Project Objective
The main objective of this project is to make learning fun and interactive through educational quizzes.
